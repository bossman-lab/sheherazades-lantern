# 今日AI简报 — 资本竞赛

▸ Anthropic Q1收入暴增80倍至$44B年化营收，首次超越OpenAI。同期签下$200B谷歌云协议+SpaceX Colossus 1(22万GPU)全部算力，发布Claude Code Auto Mode和Agent SDK。AI军备竞赛已到新量级。@CNBC @AIWeekly

▸ 中国国家大基金洽谈领投DeepSeek首轮融资，估值$45B——与西方前沿实验室平起平坐。DeepSeek V4已开源，R2推理模型仍在路上。主权资本正直接定价前沿模型估值。@Bloomberg

▸ SpaceX计划在德州建造Terafab芯片工厂，投资$55B起，总投入或达$119B——超越Intel俄亥俄和台积电亚利桑那。结合与Anthropic的算力协议，Musk正以非云厂商身份构建AI基础设施。@TechCrunch

▸ Figure AI Helix-02双机器人协作演示：两台Figure 02在两分钟内完成开门、挂衣、铺床等全套卧室整理，无中央控制器、无通信，仅靠视觉推断意图。BotQ工厂产能升至每小时1台，Figure 04进入后期设计，CEO称之为人形机器人的"iPhone 1时刻"。@极客公园 @FigureAI

▸ GPT-5.5 Instant成为ChatGPT默认模型，AIME数学81.2分（上代65.4），幻觉在法律/医疗/金融领域显著降低。同时引入"记忆来源"功能，让用户知道个性化回答用了哪些上下文。@TechCrunch

总结：AI赛道从模型之争全面转入资本+基础设施竞赛，中国DeepSeek有了主权资本背书，人形机器人开始处理柔性协作任务。
