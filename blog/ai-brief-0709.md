今日AI简报 — 开源模型与AI治理

▸ **xAI 正式更名为 SpaceXAI** — 马斯克在 SpaceX IPO 后将 xAI 并入 SpaceX 品牌体系，X 账号更名 @SpaceXAI 并启用新 logo。虽 API 端点、开发者集成暂未变动，但品牌策略信号强烈：Grok 将从独立 AI 产品并入 SpaceX 的"AI+火箭"叙事。此前 SpaceX 于 2 月完成对 xAI 的收购，此次更名是整合的重要一步。

▸ **腾讯开源 HY3：295B MoE 模型免费开放** — HY3 是一个 295B 参数的 MoE 模型，每次推理仅激活 21B 参数，定位为开源智能体基础设施。Apache 2.0 许可，已在 OpenRouter 免费上线（至 7 月 21 日）。实测显示其在 Agent 任务、浏览器操作、工具调用等场景表现突出，被称为"更便宜的 Agent 底层"。Hugging Face 上完整版 598GB，FP8 量化版 300GB。

▸ **联合国首届 AI 治理对话在日内瓦闭幕** — 7 月 6-7 日，193 个成员国齐聚日内瓦 Palexpo 会展中心，讨论 AI 安全、责任归属、人类监督等议题。美国代表强调"为公民释放 AI 福利"，各国就 AI 安全与责任达成共识性立场，但未形成任何约束性协议。对话纳入联合国全球数字契约框架，下一届会议预计持续推进。

▸ **Agent 框架 > 模型质量成新共识** — 多家评测指出 Claude Code、Codex、OpenCode 在编码质量上已几乎持平，决定胜负的因素从底层模型转向 Agent 框架（harness）。Omnigent 等元框架应运而生，支持跨 Agent 编排（Claude 实现 + Codex 审查），具备治理层和人类在环能力。行业分析认为，2026 年的竞争焦点已从"谁的模型更强"转为"谁的框架更能让模型稳定可靠地完成长任务"。

总结：本周关键词是"基础设施化"——无论是腾讯开源大模型、联合国治理框架，还是 Agent 框架竞赛，AI 产业正从模型能力比拼转向生态和治理层面的基础设施构建。
